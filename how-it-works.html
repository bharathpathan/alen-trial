How Project ALEN actually works

ALEN keeps one model of your system and runs everything around it on your own machine. Here is what happens when you import code, start something new, or ask an agent for a change, and where your data goes (it stays with you).

Local-first by design

Your code and your data stay on your machine

ALEN is an extension that runs inside VS Code on your computer. The architecture model, the code index, memory, drafts, run history and logs are plain files in your project's .ai-architect folder and in your home folder. There is no Project ALEN server that receives your code.

  • Use a local model and nothing leaves at all. Ollama, llama.cpp, vLLM or any OpenAI-style server on your machine or network.
  • Use a cloud model and you choose what goes. Only the context a task needs, after secrets are redacted, straight from your machine to the provider you configured, with your own key.
  • Private folders never leave. Mark them once; only local models may read them.
  • The only call to us is the key check: the key, nothing else.

Import existing code

From a repository to an architecture you can trust

Open any folder and ALEN reads it in layers, cheapest and most certain first. Facts come from the code itself; AI only fills the gaps, and everything it adds is checked against those facts before you see it.

  • Real parsers, not guesses: syntax trees for each language, 34 framework packs (Spring, ASP.NET Core, Django, Rails, NestJS, FastAPI, Go, Rust, Next.js and more).
  • What is deployed, not just written: Compose, Kubernetes, Helm, Terraform, OpenAPI, AsyncAPI, proto and GraphQL files add evidence.
  • Every row has a source and a confidence. AI-only findings start unticked, and the report names what could not be seen.
  • You review, then accept. Nothing enters the model until you say so.

Requirements first

ALEN checks what you wrote for missing entities, validation, authorisation and error behaviour, and asks before anything is generated.

Real scaffolds

Spring Boot, Express, FastAPI and React/Vite projects with OpenAPI contracts, Dockerfiles, Compose, hardened Helm charts, CI workflows and an ADR.

Honest about done

Generated code is a start. ALEN tracks what is still a stub, and only calls a route done when a test calls it.

The AI engine

One engine, one loop, you in charge

Every piece of agent work, whether from chat, a schedule or the editor, goes through the same engine. A primary agent owns the plan and the edits and calls in specialists (analyst, reviewer, tester, security) only when needed.

Any model, routed by results

OpenAI, Anthropic, Gemini, local and compatible endpoints. ALEN measures which model does which task well and routes there, with failover chains and budgets.

Guardrails on every tool call

Permission rules, workspace trust, a data classifier that keeps sensitive files away from cloud models, and secret redaction on every request.

Pause, resume, replay

Runs survive a restart. Approvals wait for you; work done while you were away lands in the inbox, never in your branch.

Verification

Proof climbs a ladder

Each change climbs from the cheapest check to the most thorough. A failing rung stops the climb and goes back to the agent for repair; a tool that is not installed is skipped and named, never silently passed.

  • Affected tests only, chosen from the code graph, so checks stay fast.
  • Mutation spot checks prove the tests would catch a broken change.
  • Evidence is recorded with the run, in a tamper-evident log.

Memory

It remembers, on your machine

Two kinds of memory, both plain files you can read, export or clear.

Project memory

In the project's .ai-architect folder.

  • Decisions, next steps, a glossary of domain terms
  • How to build and test, conventions and pitfalls agents learned
  • Past fixes and playbooks, offered again when they fit
  • Where you left off

Global memory

In your home folder, for every project.

  • Recent projects, pinned favourites
  • Your own rules for every project
  • Saved prompts and AI connections
  • Your subscription and time left
